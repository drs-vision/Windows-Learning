# CoinQuest — status & decisions (2026-10-11)

Repo: https://github.com/drs-vision/Windows-Learning — pushed 2026-10-11; first CI build green; installer at https://github.com/drs-vision/Windows-Learning/releases/latest (`CoinQuest-Setup-0.1.N.exe`, ~97 MB, bundles .NET 8 runtime + WebView2). Full design in `docs/ARCHITECTURE.md`; parent-facing manual in `docs/PARENT_GUIDE.md`.

## What it is
Windows software that locks a child's account to an allowlist (apps + websites), pays **coins** for learning, and sells **prizes** (YouTube minutes, arcade minutes, real-world rewards). Parent's own account is never restricted. Self-updates from GitHub Releases on every push to `main`.

## Decisions locked in
- Child is 11 → TypingQuest starts at touch-typing fluency with a placement test; reading passages + comprehension questions instead of phonics.
- Both Edge and Chrome locked via per-user browser policy (HKU\<SID>); parent hive untouched.
- Local-first, single machine; every record carries householdId/childId so multi-family/cloud can be added later without migration.
- Scripture typing uses KJV (public domain, bundled starter of 20 passages; full text fetched at build).
- Arcade: Ruffle (open-source Flash emulator) + only games with verified redistributable licenses (5b, Ending, Red Rogue [off by default], 2048, Hextris, HexGL, micropolisJS, T-Rex Runner, Underrun, Astray, Blockrain, Space Invaders, Clumsy Bird). Parents can drop their own .swf files into `C:\ProgramData\CoinQuest\arcade`.
- Coins are minted only by the Windows service (runs as SYSTEM). The same pure scoring code the UI runs is re-executed inside the service (Jint sandbox) — UI numbers are never trusted. Ledger is SQLite with a SHA-256 hash chain.
- Updates: custom updater against GitHub Releases (zip + sha256), applies when the child logs off.

## Reading quest (Nov 2026)
- New **Reading** quest: public-domain books sorted by US grade level. Parents pick allowed books (Ways to earn → Reading → Edit; default all). Kid reads a chapter, takes a quiz of clamp(round(words/250), 4, 10) questions drawn from a bank 1.5-2x that size (unseen first, choices shuffled every time). 70% passes and pays coins per right answer; a fail starts a retake timer (default 10 min) and the chapter stays open to reread. After passing, unseen questions become bonus questions. Typing mode (toggle) also pays 1 coin per N words. A ⚑ flag drops a bad question from the score and is listed for the parent.
- Starter shelf (6 books, 140 chapters, 1,566 original questions): McGuffey's First Reader (K-1), Peter Rabbit (K-2), Aesop for Children (2-4), Black Beauty (4-6), The Wind in the Willows (5-7), Treasure Island (6-8).
- Content lives in `content/books/<book>/` as plain files (book.json, chapter .txt, chapter .questions.json); `content/books/README.md` + `schema/` describe the format for any person or AI editing questions. `scripts/books/validate.mjs` runs in CI and checks keyboard-only text, bank size, 4 unique choices, evidence quotes found verbatim in the chapter, and that neither "longest" nor "shortest" answer is a giveaway (≤40% per chapter; currently ~23% / ~16%). `scripts/books/import_gutenberg.py` adds books.

## Reading analysis + quiz stays put (Nov 2026)

## Reading Quest (Nov 2026)
- Own card (Reading group): an endless stream of paragraphs with their question(s) under them: no start/finish screens or set length; it opens straight on a paragraph and "Next paragraph" (after every question on it is answered) brings another, until nothing is left. A trail of the last 10 answers shows right/miss; the daily coin limit caps pay, not reading. Module `reading-quest` (src/web/src/modules/reading-quest), engine `src/Shared/Books/ReadingQuest.cs` (unit-tested), content `content/passages/*.json` (format in its README, checked by `scripts/passages/validate.mjs` in CI).
- Longer paragraphs at higher levels: up to 120 words below readability grade 3, 200 at grade 3-5, 280 from grade 5; one question per ~100 words (1 up to 120 words, 2 up to 200, 3 up to 280; enforced by the validator). Matchmaking also leans towards longer paragraphs as the rating rises (target length 60 + 35 x (R - 2) words, 60-230).
- Each question is marked, paid and counted for the streak the moment it's clicked, in any order. A right question is done for good. A missed question reveals nothing (no right answer, highlight or explanation; the PC withholds them) and comes back by itself (choices reshuffled) no sooner than the next day, taking turns with new paragraphs: no pay, no rating/streak change; a second miss retires it and only then shows the answer with the supporting words highlighted. A paragraph is only shown while it has a question he may answer, and only those questions. State is per question ("id#n"); older saved states are upgraded on load. Explanations are never shown to children.
- Matchmaking: Elo-style rating on the readability-grade scale (p = 1/(1+10^((d-R)/2)), K 0.8 then 0.4); next paragraph near R+0.3, about a grade easier after 2 misses in a row.
- One level scale with Books (`src/Shared/Books/ReadingLevels.cs`): Level 1 below grade 2, then Level N = grade N to N+1. Books: the whole number of the published ATOS book level (validator-checked; Tom Kitten, Ginger and Pickles, Aesop placed by hand). Quest: level of text he gets about 3 in 4 right = floor(rating - 1) (p = 0.76 one grade under the rating, near the books' 70% pass mark). Shelf now: L3 Mrs. Tittlemouse; L4 the other Potter tales; L5 Dolittle, Tailor, Aesop; L7 Jungle Book, Kidnapped, Black Beauty; L8 Call of the Wild, Wind in the Willows, Treasure Island; L9 Around the World.
- Read first: a circle drains for 15-30 s (4 words/s; no text or number), then the answers open; the PC refuses earlier answers. Pay: 1 coin per 100 words of the paragraph shared by its questions (rounded up, min 1) x setting.
- The child can highlight words in the paragraph while questions are open (select to highlight, select again to clear, same as Books); highlights clear when the paragraph's questions are all answered.
- Streak ring: split into N parts (option, default 2); each right answer fills a part; a full ring adds 1 to the middle number and pays it (max 3). A miss empties it.
- Content: 373 short one-question paragraphs (k1-g8 files) plus longer multi-question ones (long-*.json). All human-written: CC BY 4.0 picture books (African Storybook, Pratham/StoryWeaver, Storybooks Canada via global-asp GitHub repos, author credited) and plain-English public-domain children's books (Burgess, Baldwin, Fabre, van Loon via GITenberg). Only questions are AI-written. US-gov kids' science pages would be good but need web fetching (not allowed from the workspace).
- Parents: Reading analysis → Reading Quest section: rating (+ trend), % right, streak, time, accuracy by skill and by paragraph difficulty; explainer covers the rating and the shared level scale. Daily/weekly report tile "Reading Quest".

## Books: quizzes optional, reading tracked (Nov 2026)

## Site window: modern sites load whole, Back / Forward / Reload (Nov 2026)
- Problem: the gate (NetGate) only let through hosts on the list plus a short built-in list, so modern sites, which load scripts, images, video and APIs from many other hosts, loaded half-broken.
- Fix: the kid app's site window (GameWindow, used for allowed websites and web arcade games) watches the page's own requests (WebView2 WebResourceRequested). The first time an allowed page needs a host the gate doesn't know, the request waits while the window tells the Guardian (`shell.pageParts` {site, hosts}); the gate then lets that host through as "part of <site>" for 12 hours, only while <site> is still allowed (a listed site, its known companions, a site unlock or arcade time; never CoinQuest's own pages, sign-in hosts or the YouTube player). These hosts are never destinations: the window still refuses to navigate to any host not on the list. The Guardian accepts `shell.pageParts` only from the installed kid app (it checks the connecting program's file is InstallRoot\CoinQuest.Scholar.exe via GetNamedPipeClientProcessId; the child can't change that folder).
- Plain-HTTP requests through the gate now use one connection each (Connection: close), so a kept-alive connection can't carry an unchecked request for another site.
- The site window's bar: 🏠 Back to CoinQuest (or Esc), then ← Back, → Forward, ⟳ Reload for the page (dimmed when there's nowhere to go; Alt+Left / Alt+Right / F5 work too).
